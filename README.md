# MVP-2: Model Quality Evaluation

## SkillFactory Data Science Program

Thematic repository for studying model evaluation techniques,
data splitting strategies, validation approaches,
performance metrics, and practical machine learning assignments.

---

## Goal

Study the principles of machine learning model evaluation,
understand when and why data should be split into training,
validation, and test sets, and learn how to correctly assess
model quality using appropriate metrics and validation methods.

---

## Topics Covered

- Train/Test Split
- Cross-Validation
- Model Evaluation Metrics
- Classification Metrics
- Regression Metrics
- Overfitting and Underfitting
- Validation Strategies
- Error Analysis
- Model Comparison
- Practical Quality Assessment of Machine Learning Models

## Learning Outcomes

By completing this module, I will be able to:

- Properly split datasets for model development
- Select appropriate evaluation metrics
- Apply train/test and cross-validation techniques
- Identify overfitting and underfitting
- Compare competing models objectively
- Interpret model performance results
- Make data-driven decisions about model quality
